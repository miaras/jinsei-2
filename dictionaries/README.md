# Dictionary data

The compressed indexes in this directory are generated by `scripts/build-dictionaries.mjs` and are used for local, offline lookups in JINSEI.

- `japan.json.gz` is derived from the UTF-8 EDICT2 distribution of JMdict/EDICT by the Electronic Dictionary Research and Development Group. Use and redistribution are subject to the [EDRDG dictionary licence](https://www.edrdg.org/edrdg/licence.html). This product uses the JMdict/EDICT dictionary files in accordance with that licence.
- `china.json.gz` is derived from CC-CEDICT, published by MDBG and licensed under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). The bundled snapshot came from the `cjhoward/cedict-tts` mirror.
- `korea.json.gz` is derived from [Kengdic](https://github.com/garfieldnate/kengdic), Joe Speigle's Korean/English dictionary database, used under the [Mozilla Public License 2.0](https://www.mozilla.org/MPL/2.0/).

The generated indexes preserve dictionary attribution and licensing metadata in the files themselves. Rebuild them by placing `edict2u.gz`, `cedict_ts.u8`, and `kengdic.tsv` in a source directory and running:

```sh
node scripts/build-dictionaries.mjs /path/to/source-directory
```
